## 2. Votre compte

Vous créez un compte avec un identifiant public (`@identifiant`) et une adresse e-mail. Vous protégez votre mot de passe et vos jetons du CLI ; toute action faite avec eux est réputée faite par vous. La double authentification est conseillée.

Vous retirez ce qui identifie votre production (adresses, noms, valeurs réelles). Sont interdits : les logiciels malveillants, les contenus illégaux, le code copié sans respecter sa licence et le harcèlement.

Un kory s'utilise selon sa licence. KoryHub ne garantit pas qu'un kory convient à votre usage : relisez le code avant de l'utiliser, en particulier un module non certifié. Le nombre de téléchargements par heure est limité.

## 7. Suspension et suppression

Vous pouvez supprimer votre compte à tout moment depuis vos réglages : vos données personnelles sont effacées, vos modules privés supprimés, vos modules publics restent sous votre identifiant. Un compte qui enfreint ces conditions peut être suspendu ou supprimé.
