# Getting started

KoryHub is a registry of **kory**: pieces of code proven in production, with their documentation and architecture, that you share and others reuse. The website is for finding and reading kory; the `kory` CLI is for publishing them and adding them to your projects.

## The journey in 4 commands

1. Link your terminal to your account:

```
kory login
```

2. Prepare a kory in your project:

```
kory init payment
```

3. Publish it:

```
kory push payment
```

4. Add someone else's kory to another project:

```
kory pull @moussa/mobile-money-resilient
```

Each step is described in the next pages: [Install the CLI](install), [Publish](publish), [Use a kory](integrate).

## What you need

- A KoryHub account, with a verified email address to publish.
- The `kory` CLI, a single file with no dependencies, for Windows, macOS and Linux.

## Where to find help

- `kory help` lists the commands; a command used incorrectly shows its correct form.
- Error messages always say what is blocking and what to do.
- Moderation and certification rules are on the [Governance](https://koryhub.dev/governance) page.
