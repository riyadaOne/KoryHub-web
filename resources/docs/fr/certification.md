# Certification « Vérifié en Prod »

Le badge « Vérifié en Prod » signifie qu'une personne de l'équipe de modération a examiné l'architecture et la documentation d'une version précise. Il est toujours accordé par une personne, jamais automatiquement.

## Ce que garantit le badge

Une architecture déclarée et cohérente, et une documentation qui explique le problème et les pièges. Le badge porte sur **une version** : une nouvelle version n'est pas certifiée tant qu'elle n'a pas été examinée.

## Les 5 contrôles préliminaires

Avant la demande, KoryHub vérifie que :

1. l'architecture est déclarée (`kory graph`) ;
2. le README contient « Problème résolu » et « Pièges évités » ;
3. la licence fait partie de la liste officielle ;
4. la version est publiée, ni dépréciée, ni retirée, ni à risque ;
5. aucun dossier n'est déjà ouvert pour ce module.

Le module doit aussi être public et votre adresse e-mail vérifiée.

## Demander

Depuis la page de la version : « Demander la certification ». Vos dossiers sont dans votre tableau de bord, rubrique « Mes certifications ».

## Complément, décision, rapport

L'équipe peut vous demander un complément : répondez par un message, ou proposez une nouvelle version (les contrôles sont relancés). À la décision, vous êtes prévenu. Une certification accordée produit un rapport PDF dans votre langue et en anglais, téléchargeable depuis la page de la version.

## Révocation

Le badge peut être révoqué, avec un motif, si un problème est découvert. Le rapport reste téléchargeable, mais la page de la version fait foi.
