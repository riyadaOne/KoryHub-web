# ابدأ

KoryHub سجلّ لـ **kory**: أجزاء من الشيفرة أثبتت جدواها في الإنتاج، مع توثيقها وبنيتها، تشاركها أنت ويعيد الآخرون استخدامها. الموقع للبحث عن kory وقراءتها؛ وأداة سطر الأوامر `kory` لنشرها ودمجها في مشاريعك.

## المسار في 4 أوامر

1. اربط الطرفية بحسابك:

```
kory login
```

2. حضّر kory في مشروعك:

```
kory init payment
```

3. انشره:

```
kory push payment
```

4. ثبّت kory شخص آخر في مشروع آخر:

```
kory pull @moussa/mobile-money-resilient
```

كل خطوة مشروحة في الصفحات التالية: [تثبيت أداة سطر الأوامر](install)، [النشر](publish)، [دمج kory](integrate).

## ما تحتاج إليه

- حساب على KoryHub، مع بريد إلكتروني مؤكَّد للنشر.
- أداة `kory`، ملف واحد دون أي اعتماديات، لأنظمة Windows وmacOS وLinux.

## أين تجد المساعدة

- يعرض `kory help` قائمة الأوامر؛ والأمر المستخدم خطأً يعرض صيغته الصحيحة.
- تقول رسائل الخطأ دائمًا ما الذي يمنع وما العمل.
- قواعد الإشراف والاعتماد موجودة في صفحة [الحوكمة](https://koryhub.dev/governance).
