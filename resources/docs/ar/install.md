# تثبيت أداة سطر الأوامر

`kory` ملف تنفيذي واحد دون أي اعتماديات. ينزّل سكربت التثبيت الإصدار المنشور، **ويتحقق من بصمة SHA-256**، ولا يثبّته إلا إذا تطابقت. لا حاجة إلى صلاحيات المسؤول.

## Windows

في PowerShell:

```
irm https://koryhub.dev/install.ps1 | iex
```

يُثبَّت `kory.exe` في `%LOCALAPPDATA%\Programs\kory`، ويُضاف هذا المجلد إلى PATH. افتح بعد ذلك طرفية **جديدة**.

## macOS وLinux

في طرفية:

```
curl -fsSL https://koryhub.dev/install.sh | sh
```

يُثبَّت `kory` في `~/.local/bin`. إذا لم يكن هذا المجلد في PATH، يعرض السكربت السطر الذي تضيفه إلى `~/.profile`.

## التحقق من التثبيت

```
kory version
```

يعرض الأمر الإصدار المثبَّت وينبّهك إذا توفر إصدار أحدث.

## إذا منع PowerShell تشغيل السكربت

إذا رفض PowerShell تشغيل السكربتات، اسمح بها لحسابك فقط، ثم أعد تشغيل أمر التثبيت:

```
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

الملفات التنفيذية غير موقَّعة بعد: قد يعرض Windows تحذيرًا عند التشغيل الأول.

## التحديث

عند توفر إصدار جديد، ينبّهك `kory` مرة واحدة في اليوم على الأكثر. لا يحدّث نفسه أبدًا: أعد تشغيل أمر التثبيت.

## إلغاء التثبيت

احذف الملف `kory` (أو `kory.exe`)، وإن شئت مجلد إعدادات kory في مجلد إعدادات المستخدم. وألغِ كذلك رمز الطرفية من إعداداتك على الموقع.
