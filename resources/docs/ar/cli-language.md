# لغة أداة سطر الأوامر

تتحدث `kory` العربية والفرنسية والإنجليزية والبرتغالية.

## لغة النظام

افتراضيًا، تستخدم الأداة لغة نظامك إذا كانت إحدى اللغات الأربع، وإلا فالإنجليزية.

## اختيار اللغة

```
kory config set lang ar
```

اللغات: `en` و`fr` و`ar` و`pt`. لمعرفة اللغة المختارة:

```
kory config get lang
```

## رسائل الواجهة البرمجية

رسائل الخطأ التي ترسلها الواجهة البرمجية (رفض إصدار الأداة، حدّ التنزيل…) يكتبها الخادم ويترجمها بلغة الأداة: تُعرض كما هي.
