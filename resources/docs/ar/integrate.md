# دمج kory

تثبّت الأداة kory في مشروعك، وتحتفظ بأثر ما كتبته، وتترك لك دائمًا الكلمة الأخيرة في ملفاتك.

## البحث

```
kory search payment mobile
kory info @moussa/mobile-money-resilient
```

يقبل `search` الخيارات `--category` و`--language` و`--limit`. ويعرض `info` الوصف والإصدارات والترخيص والمتطلبات والبنية.

## التثبيت

```
kory pull @moussa/mobile-money-resilient
```

تعرض الأداة المتطلبات التي تثبّتها بنفسك، وتسأل عن مجلد التثبيت (أو `--dir <folder>`)، ثم تنزّل، **وتتحقق من البصمة**، وتكتب الملفات. لإصدار محدد: `kory pull @moussa/mobile-money-resilient@1.1.0`. يُنبَّه إلى الوحدة غير المعتمدة أو الإصدار الموقوف قبل التثبيت.

## الملفات الموجودة مسبقًا

لكل ملف موجود، تختار: الإبقاء، أو الاستبدال، أو عرض الفرق. ودون طرفية (سكربت، تكامل مستمر) تبقى ملفاتك دائمًا كما هي.

## التحديث

```
kory update @moussa/mobile-money-resilient
```

تعرض الأداة الإصدار الجديد وتطلب التأكيد. الملف الذي عدّلته منذ التثبيت لا يُستبدل أبدًا دون موافقتك.

## الإزالة

```
kory remove @moussa/mobile-money-resilient
```

تُحذف ملفات kory؛ أما التي عدّلتها فلا تُحذف إلا بعد تأكيد ثانٍ.

## العرض والفحص

يعرض `kory list` قائمة kory المحضّرة في هذا المشروع. لفحص kory المثبّتة:

```
kory audit
```

يُفحص كل kory في `kory.lock`: محدَّث، تحديث متاح، موقوف، معرّض للخطر، مسحوب أو غير موجود. رمز الخروج 1 إذا كان إصدار مسحوبًا أو معرّضًا للخطر: مفيد في التكامل المستمر.

## الملف kory.lock

في جذر المشروع، يسجّل لكل kory الإصدار وبصمة الأرشيف ومجلد التثبيت وبصمة كل ملف. احفظه مع شيفرتك في نظام إدارة الإصدارات.
